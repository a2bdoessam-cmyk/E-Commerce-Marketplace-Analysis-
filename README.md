 Project Overview
This project is an end-to-end data analysis solution for e-commerce businesses. It includes a robust data pipeline for cleaning and processing sales data, followed by an interactive dashboard built with **Streamlit**.

 Key Features
- **Automated Data Cleaning:** Scripts to handle missing values and data inconsistencies.
- **Financial KPIs:** Real-time calculation of Total Revenue, Profit Margins, and Order Trends.
- **Interactive Dashboard:** Dynamic visuals and filters to explore marketplace performance.
- **Professional UI:** Custom CSS styling for a modern business look.

 Tools Used
- **Python:** Pandas, NumPy, Streamlit.
- **Visualization:** Matplotlib, Seaborn, and Power BI integrated insights.
